# Vercel Deployment - Quick Start

Deploy your entire Sage 50 Journal Entry Sync app to Vercel in 10 minutes.

## 🚀 Quick Deploy

### Step 1: Install Vercel CLI and Dependencies

```bash
npm install -g vercel
npm install
```

### Step 2: Run Deployment Script

```bash
./scripts/deploy-vercel.sh
```

**Or manually**:

```bash
# Build
npm run build

# Deploy
vercel --prod
```

### Step 3: Set Environment Variables in Vercel

After deployment, go to **Vercel Dashboard** → **Your Project** → **Settings** → **Environment Variables**:

```
SHOPIFY_API_KEY=your_api_key
SHOPIFY_API_SECRET=your_api_secret
DATABASE_URL=postgresql://user:pass@host/db
BLOB_READ_WRITE_TOKEN=(auto-generated by Vercel)
CRON_SECRET=your_random_secret_string
```

**To generate CRON_SECRET**:
```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

### Step 4: Set Up Database (Vercel Postgres - Easiest)

**In Vercel Dashboard**:
1. Go to **Storage** tab
2. Click **Create Database**
3. Select **Postgres**
4. Name: `sage50-sync-db`
5. Click **Create**

Vercel will automatically add `DATABASE_URL` to your environment variables.

### Step 5: Update Prisma Schema

Already configured for PostgreSQL! Just migrate:

```bash
# Set DATABASE_URL locally for migration
export DATABASE_URL="your_vercel_postgres_url"

# Run migration
npx prisma migrate deploy
```

### Step 6: Update Shopify App Configuration

Get your Vercel URL (e.g., `https://sage50-sync.vercel.app`)

Update `shopify.app.toml`:

```toml
application_url = "https://sage50-sync.vercel.app"

[auth]
redirect_urls = [
  "https://sage50-sync.vercel.app/auth/callback",
  "https://sage50-sync.vercel.app/auth/shopify/callback"
]
```

### Step 7: Redeploy to Shopify

```bash
shopify app deploy --force
```

### Step 8: Test!

1. Go to Shopify Admin
2. Open your app
3. Should now load correctly!
4. Go to Export Center
5. Generate a CSV

## 🐛 Troubleshooting

### "Blob not found" errors

**Fix**: Ensure `BLOB_READ_WRITE_TOKEN` is set in environment variables

### Cron job not running

**Fix**:
1. Verify `vercel.json` has cron configuration
2. Check Vercel Dashboard → Cron tab
3. Ensure `CRON_SECRET` is set

### Database connection errors

**Fix**:
1. Verify `DATABASE_URL` is set
2. Run: `npx prisma migrate deploy`
3. Check database is accessible from Vercel
